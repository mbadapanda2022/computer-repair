🛠 Demo Software Kaise Handle Karein

Ye guide aapke liye hai (jise buyer ko demo dena hai). Buyer ke liye alag se software ke andar hi Hindi-English tutorial hai (demo-guide shortcut).

1. Aapke paas kya bana hai

CheezKahan haiKaam
RepairShopDemo-Setup.exeG:\computer_repair\demo_package\output\Ye ONE file buyer ko bhejni hai (45 MB). Iske alawa kuch bhejne ki zaroorat nahi.

2. Buyer ko kaise dein (3 step)

  1. File bhejein: RepairShopDemo-Setup.exe ko WhatsApp document / Google Drive link / pen drive se bhejein.
  2. Sirf 3 baatein bataayein:
    • File par double-click karke Install karo ("Next-Next" jaisa normal software).
    • Install ke baad Desktop icon "Repair Shop Demo" double-click karo — website apne aap khul jayegi.
    • Login: Admin / Demo@12345 (staff) aur demo_customer / Demo@12345 (customer portal).
  3. Ek line add karein: "Pehli baar open karne me 2-3 minute lagte hain (data set hota hai) — browser tab khulne tak wait karein. Internet ki zaroorat nahi, sab data aapke computer par rehta hai."

Buyer ko Python ya kuch install nahi karna — ye ek hi file ka poora software hai.

3. Trial ka system (kya hoga 6 mahine baad)

  • Chalu ke pehle open se 180 din (6 mahine) ka timer shuru — buyer ke computer par hi note hota hai.
  • Expiry se 30 din pehle har page par yellow warning banner dikhega, aur usme aapka phone aur WhatsApp button hoga.
  • 6 mahine baad poora software ek screen par badal jayega: "Demo Trial Expired" — usme aapka naam, phone (7008601963) aur WhatsApp (wa.me/918895745441) buttons honge. Buyer wahin se aapko contact karega.
  • Timer delete/clock-change se dhokha nahi de sakta (do jagah save hota hai) — simple protection.

⚠️ Ek baat dhyan rakhein: jab bhi aap naya build banayein, usme ek "hard deadline" (build date + ~6.5 mahine) baked hoti hai — purane builds apne aap band ho jaate hain. Isliye har mahine ke aas-paas ek naya Setup.exe build karke rakhna best rahega.

4. Demo me kya-kya dikhega (buyer poora professional use kar sakta hai)

  • Billing/GST invoices, repairs ka job-card (estimate → WhatsApp → invoice), purchases, stock, cash/bank book, P&L / Balance Sheet / Trial Balance / GST reports, customer portal, notifications, keyboard shortcuts — sab 6 mahine unlimited. Buyer apni company ka naam Settings me bharega to poori site uske brand ho jayegi.
  • Sirf email OTP/demo emails bahar nahi jayenge (local demo hai) — baaki 100% same.

✔ Aapka koi bhi real/production data is demo me nahi hai — sirf nakli "Demo Computer Care" dukaan ka data hai. Aapki live website (a1computersolutions.in) bilkul safe hai.

5. Uninstall / dobara install

  • Uninstall: Windows Settings → Apps → Repair Shop Demo → Uninstall. Desktop icon aur data folder dono delete ho jaate hain.
  • Dubara install karne par fresh demo data ban jayega.
  • Aap khud test karne ke liye: demo aapke PC par abhi chal raha hai — http://127.0.0.1:8777/ browser me kholo.

6. Naya build kabhi banana ho (optional)

Sirf tab jab purana demo expire ho gaya ho ya naye features daale ho. Poore steps file me hain: G:\computer_repair\demo_package\BUILD_DEMO.md. Ya mujhse bas bolo — "naya demo build karo" — main bana dunga.

7. Render Cron job — AB ZAROORI NAHI (automatic ho gaya)

Pehle main aapko Render me Cron Job banane bola tha. Maloom hua ki Render ke free plan me Cron Jobs feature hi nahi hai (paid) — isliye aapko option nahi dikh raha tha. Aapne galat kuch nahi kiya.

✔ Maine free alternative bana diya hai: GitHub ka automatic scheduler roz subah 6 baje aapki website ka /keepalive/ URL hit karta hai. Isse (1) Supabase database 7 din idle hone par pause nahi hota, (2) storage snapshot note hota hai, (3) database 80% bhara to aapko email alert aata hai.

Aapko iske liye Render ya GitHub me kuch click karne ki zaroorat nahi — sab automatic hai. Verification bhi ho gaya: live website par heartbeat chala (19.2 MB / 500 MB = 3.8% used). Bas kabhi-kabah GitHub par computer-repair → Actions tab khol ke green tick dekh lena (optional).
