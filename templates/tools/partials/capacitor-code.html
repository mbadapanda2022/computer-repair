{# Capacitor marking decoder #}

Capacitor Code Decoder

Ceramic and multilayer chips use a 3-digit pico-farad code (104 = 10 × 10⁴ pF = 100 nF). Film and electrolytic parts use a letter as the decimal point (4n7 = 4.7 nF, 2u2 = 2.2 µF).

Capacitance
—
European markings that use M as the decimal point (4M7) mean the same thing as 4u7 — type it with u here. Always discharge a capacitor through a resistor before you touch the legs; a large electrolytic can bite even when the board is off.
