How this database stays safe on the free plan
1. Never paused or deleted

Supabase pauses free projects after 7 days without traffic and deletes them after 30 days paused. The daily storage_watchdog job (Render Cron) touches the database every day, so the project never sleeps — and it also takes the size snapshot you see above.

2. Warning before the limit

When usage crosses {{ alert_pct|floatformat:0 }}%, the watchdog emails the admins (once per week at most) with exact steps: run Safe Cleanup, take a backup, or upgrade. Free quota is {{ quota_display }}; Supabase Pro is about $25/month with 8 GB if you ever need it.

3. Backups

Free plan does not keep automatic backups. Take one any time from Staff Portal → Backup & Restore, or download a SQL dump from the Supabase dashboard (Database → Backups / SQL Editor).
